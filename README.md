# Fokir - Personal Portfolio

A responsive personal portfolio website built to showcase my skills, services, projects, and professional activities.

The website focuses on creating a clean and modern layout with responsive design across desktop, tablet, and mobile devices.

* Responsive navigation
* Hero section
* About section
* Services section

* Contact section

## Responsive Design

The website uses custom CSS media queries to adapt the layout and content to different screen sizes, including desktop, tablet, and mobile devices.
